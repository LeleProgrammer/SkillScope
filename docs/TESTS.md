# 测试设计、难度与评分

本文件对应 1.0.0。实际公式见 `assets/core.js`，运行参数见 `assets/games.js`。所有参数都是本项目的训练设计，不是人群常模。

## 共同约定

- 训练分计算后截断到 `[0, 100]`，四舍五入为整数。
- 下文“率”均为 `0–1` 小数，界面以百分数显示。
- 计时采用 `performance.now()`；目标信号在 `requestAnimationFrame` 更新并绘制的帧记录起点。
- 一轮前有 3 秒准备倒数。练习与正式玩法一致，练习不保存。
- 切换后台、窗口失焦、Esc、触摸取消或手动退出，中止本轮，不记成绩。
- 有时限的项目，时限到达后的输入不继续计数。
- 鼠标只计主按钮，触摸只计主指针。键盘忽略系统长按连发，并要求松键后再输入。
- 未命中时不伪造有效反应样本：无正确响应的平均正确反应 / 命中偏差显示为 `—`；评分使用公式规定的缺失惩罚。其他计数仍为 0。
- 测试画布采用 960 × 520 逻辑坐标。平均偏离以逻辑 px 表示，不是物理屏幕像素。

## 1. 基础反应

共完成 7 次有效信号。等待间隔随机为约 1–3 秒，避免固定节奏预判。绿屏后点击或空格；提前操作计抢跑，重新等待，不占用有效题数。

每次信号超过 2,000 ms 未响应，该次按 2,000 ms 计入统计。这样不能通过忽略较慢题目只保留快成绩。

```text
score = (600 - median_ms) / 4.5 - 5 * false_starts
```

统计中位数、平均、最佳、总体标准差、抢跑和超时。三档难度使用相同信号条件，便于保持基础反应指标简单。

## 2. 选择反应

16 个随机方向，方向与 ←/↑/↓/→ 或 A/W/S/D 对应；触屏使用画面下方按钮。

| 难度 | 单题响应上限 |
| --- | --- |
| 入门 | 2,300 ms |
| 标准 | 1,800 ms |
| 进阶 | 1,300 ms |

每题只接受第一个方向答案。正确响应计入平均正确反应；错误或超时算未完成正确题。

```text
accuracy = correct / 16
score = (1200 - mean_correct_ms) / 9 * accuracy
```

没有正确题时，评分的反应值按 1,200 ms 处理，因此得 0 分。

## 3. 反应抑制

24 个独立随机信号，每个信号有 65% 概率为绿色目标，剩余为红色干扰。绿圈点击 / 空格；红叉不输入。

| 难度 | 信号显示 / 响应窗口 |
| --- | --- |
| 入门 | 1,100 ms |
| 标准 | 900 ms |
| 进阶 | 700 ms |

```text
accuracy = (green_hits + correct_red_rejections) / 24
score = 70 * accuracy + 30 * max(0, 1 - mean_hit_ms / 900) - 3 * extra_inputs
```

无命中时反应项按 900 ms 处理。首次红叉输入为红叉误触；信号间隔或同一信号重复输入计额外输入。漏判是未响应的绿圈。绿色圆环与红色叉号同时使用形状和文字区分，不单靠颜色。

## 4. 精准瞄准

20 秒内点击随机目标。入门 / 标准 / 进阶半径为 38 / 27 / 19 逻辑 px，目标中心位于画布内部安全区域。

```text
accuracy = hits / (hits + misses)
score = 2.5 * hits * accuracy
```

平均命中间隔包含首次目标出现到首次命中的耗时；没有命中时无有效间隔样本。

## 5. 目标切换

20 秒内依次点击编号 1–6，完成一组后重新生成。目标从分开的六个区域中生成，并随机打乱编号，避免相互遮挡。半径为 38 / 29 / 22 逻辑 px。

```text
accuracy = hits / (hits + misses)
score = 3 * hits * accuracy
```

点击错误编号或空白都算失误。平均命中间隔同精准瞄准。

## 6. 动态追踪

20 秒内跟踪由复合正弦轨迹控制的目标，入门 / 标准 / 进阶的运动倍率为 0.65 / 0.95 / 1.3，目标半径为 55 / 42 / 32 逻辑 px。

```text
accuracy = time_inside_target / measured_time
score = 100 * accuracy
mean_distance = sum(distance * frame_duration) / measured_time
```

按帧实际间隔加权，避免直接按帧数统计。没有有效指针时，以 960 逻辑 px 作为偏离惩罚，并计为不在圈内。鼠标可悬停追踪；触屏必须持续按住拖动。

## 7. 鼠标点击速度

固定 10 秒。三档条件相同；每次主按钮 / 主指针按下计数，空格无效。

```text
CPS = clicks / 10
score = 10 * CPS
```

记录逐秒点击数、最佳单秒、末三秒均值与首三秒均值之比。首三秒为 0 时，该比值使用 0，避免除零；该值不参与训练分。它只是首末段变化，不代表专业耐力指标。

## 8. 键盘操作速度

固定 15 秒：

| 难度 | 玩法 |
| --- | --- |
| 入门 | F 单键连按 |
| 标准 | F / J 交替，开始为 F |
| 进阶 | 按画面随机指令 F / J / D / K |

```text
KPS = correct_keys / 15
accuracy = correct_keys / accepted_keys
score = 20 * KPS * accuracy
```

只接受测试控制键集合：空格、方向键、W/A/S/D/F/J/K，其中不符合本题当前指令的输入计错误。其他字符与 Ctrl / Alt / Meta 组合不参与。系统连发不计为新输入。

## 9. 视觉搜索

找到唯一缺口方向不同的圆环。12 题，每题最多 6,000 ms，错点不跳题，耗时继续计算。

| 难度 | 阵列 | 与普通圆环的角度差 |
| --- | --- | --- |
| 入门 | 4 × 3 | 180° |
| 标准 | 5 × 4 | 90° |
| 进阶 | 6 × 4 | 45° |

```text
success = solved / 12
click_accuracy = solved / clicks_inside_array
score = (6000 - mean_question_ms) / 50 * success * click_accuracy
```

平均题目耗时包含超时题，每道超时按 6,000 ms 处理。阵列外点击不计为答题点击。

## 10. 空间记忆

4 × 4 格子，起始序列长度 3，按顺序亮起，完成后再输入。相邻两步不重复同一格。

入门 / 标准 / 进阶每步时长 850 / 650 / 480 ms，其中前 65% 时间亮起。序列结束后有短暂停顿。每次输入最多等 5 秒。

答对后长度加 1；错误或超时消耗一次机会，在相同长度重新生成。共 3 次机会，完成长度 12 后结束。

```text
sequence_accuracy = completed_sequences / attempted_sequences
score = 8 * longest_completed_length + 4 * sequence_accuracy
```

“最长序列”只计算完整正确的序列，不以显示过的长度代替。

## 11. 分心操作

24 秒，中心点击随机靶点，同时在两侧亮起时处理边缘信号。键盘 ←/→ 或 A/D，触屏点击相应边缘。中心目标半径为 38 / 28 / 21 逻辑 px。

边缘响应窗口为 1,500 / 1,150 / 850 ms；信号间隔随机。没有信号时按边缘为额外误按；方向错误为误判；信号消失前未操作为漏判。

```text
center_accuracy = center_hits / (center_hits + center_misses)
side_accuracy = side_hits / (signals + extra_side_inputs)
score = 50 * min(1, center_hits / 30) * center_accuracy + 50 * side_accuracy
```

边缘键和边缘区域点击不会误计为中心点击。即使窗口最后产生了信号，也需要在该轮结束前完成操作，否则作为未命中统计。

## 12. 节奏控制

24 拍，标记从右向左经过中央判定线时点击或按空格。每拍最多计一次，判定窗 ±180 ms。入门 / 标准 / 进阶为 80 / 100 / 120 BPM。

```text
mean_absolute_deviation = (sum(hit_abs_error_ms) + misses * 180) / 24
score = 100 * max(0, 1 - mean_absolute_deviation / 180) - 2 * extra_inputs
```

超出所有可命中拍的判定窗、或重复输入，计额外输入。单独列出命中平均偏差，但训练分使用包含漏拍惩罚的平均偏差。默认关闭声音，打开后提供节拍提示；声音由浏览器帧检测触发，不是音频级时钟，声画体验仍会受延迟影响。

## 六维映射与总分

| 维度 | 项目 |
| --- | --- |
| 反应 | 基础反应、选择反应、反应抑制 |
| 精准 | 精准瞄准、目标切换 |
| 追踪 | 动态追踪 |
| 速度 | 鼠标点击速度、键盘操作速度 |
| 认知 | 视觉搜索、空间记忆 |
| 协同 | 分心操作、节奏控制 |

维度分是已测项目训练分的算术平均，显示时取整数；未测维度为 `null`，不是零分。全部 12 项都有记录时，总分为 **12 项分数**的算术平均，而非六维平均，以避免维度项目数量差异产生隐含权重。

历史与报告区分难度和输入类型，但同一输入类型内仍可能存在不同刷新率或鼠标设备。项目不会自动识别硬件型号，请自行保持相同环境。
