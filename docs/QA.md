## 验证边界

自动测试使用可控时间、随机数和模拟 Canvas / DOM 事件，验证的是逻辑、状态流转、计分与数据约束，不是实际端到端输入延迟。

窄屏 iframe 验证响应式布局；触摸事件逻辑由自动测试验证。未逐一验证真实手机、平板、Safari、Firefox、不同刷新率显示器或音频硬件。部署者可按下面清单在目标设备补测。

## 后续版本手工回归建议

1. 在桌面鼠标键盘与真实手机各运行可用项目，检查点击区域与滚动行为。
2. 每项至少完成一次练习和一次正式测试，确认练习不增加历史。
3. 在倒数、等待信号、正式输入三个阶段分别按 Esc / 切换后台，确认中止。
4. 基础反应测试抢跑、超时和正常响应；选择反应测试错误键；抑制测试误触和漏判。
5. 检查追踪触屏松手、按键长按、搜索错点、记忆错误与超时、节奏重复输入。
6. 完成综合测评，检查难度锁定、下一项、最后一项报告范围与已完成记录保存。
7. 导出单项和综合 PNG，检查中文字体、长姓名与下载功能。
8. 导出 JSON，重新导入两次，确认没有重复记录；导入错误格式应显示可理解的提示。
9. 验证删单条 / 清空确认弹窗的取消与确认；仅使用可丢弃的测试数据。
10. 在无痕模式或禁用存储时检查保存失败提示，并确认当前成绩仍可导出。
11. 用 GitHub Pages 仓库子路径访问，检查静态资源、hash 页面刷新与说明文档链接。
